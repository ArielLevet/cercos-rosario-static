# Originales de las fotos

Esta carpeta está excluida de Git: **guardá un respaldo propio**, no se recupera al clonar el repo.

Una subcarpeta por categoría, con los originales JPG, PNG o WebP:

- `cercos/` → `cercos-perimetrales.html`
- `portones/` → `portones-puertas.html`
- `construccion/` → `construccion-general.html`

Las fotos se ordenan por nombre con orden numérico natural (`2` va antes de `10`).
No repetir el nombre base con distinta extensión (`01.jpg` y `01.png`).
