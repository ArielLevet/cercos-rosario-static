# Cercos Rosario

Sitio estático en HTML, CSS y un poco de JavaScript. Sin build ni dependencias.

- `index.html`, `cercos-perimetrales.html`, `portones-puertas.html`, `construccion-general.html`, `contacto.html`
- `style.css`: todos los estilos
- `main.js`: menú móvil y visor de fotos (lightbox)
- `img/`: fotos por categoría
- `CNAME`, `sitemap.xml`, `robots.txt`, `site.webmanifest`: configuración del sitio

Para verlo en local: `python -m http.server 8000` y abrir http://localhost:8000
Se publica tal cual en GitHub Pages (dominio: www.cercosrosario.com.ar).
